# 🍕 FreshBite – Online Food Ordering

FreshBite is a modern and responsive frontend web application for an online food ordering experience.

The project allows users to explore food items, add products to their cart, adjust quantities, proceed through checkout, and view an order confirmation page.

## 🌐 Live Demo

🔗 **Live Website:** https://freshbite-food-order.netlify.app/

---
 
## ✨ Features

* 🏠 Responsive food ordering homepage
* 🍔 Food item browsing
* 🛒 Add items to cart
* ➕ Increase item quantity
* ➖ Decrease item quantity
* 🗑️ Remove items from cart
* 💰 Automatic cart total calculation
* 📦 Checkout page
* 🧾 Order summary
* ✅ Order confirmation page
* 📱 Responsive design for different screen sizes
* ⚡ Interactive frontend using JavaScript
* 🎨 Modern food-focused UI

---

## 📄 Pages

### Home

The main page where users can explore the FreshBite food ordering experience.

### Cart

Displays selected food items along with quantity controls, item prices and the total amount.

### Checkout

Allows the user to enter checkout information and review the order before placing it.

### Confirmation

Displays confirmation information after the order is completed.

## 🛒 How It Works

The basic ordering flow of the application is:

```text
Home
  ↓
Browse Food
  ↓
Add to Cart
  ↓
Manage Cart
  ↓
Checkout
  ↓
Order Confirmation
```
